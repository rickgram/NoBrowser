## Keypad cursor controls

- `1`: turn cursor mode on or off
- D-pad: move the cursor; continuing at an edge scrolls the page
- Center/Enter: click
- `*` / `#`: zoom out/in
- `0`: reset zoom

Cursor and zoom shortcuts are disabled while typing. In a single-line form field, Up and Down move to the previous or next field. Multiline fields retain normal D-pad editing, and Back exits the field.
